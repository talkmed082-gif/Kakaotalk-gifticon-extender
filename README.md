# 카카오 기프티콘 유효기간 자동 연장

> 만든 이유와 동작 방식을 정리한 글: [블로그 포스트](https://claude.ai/artifact/5t4mGv2mGEgktEogxDvNAY)

gift.kakao.com 선물함 화면에서 유효기간이 얼마 남지 않은(기본 30일 이내) 기프티콘에 대해
카카오가 이미 제공하는 "기간 연장" 버튼을 자동으로 클릭해줍니다.
새로운 권한을 만들어내는 게 아니라, 사용자 본인이 로그인한 화면에서 반복 클릭을 대신 해주는 도구입니다.

## 동작 방식과 한계

- `gift.kakao.com/*` 페이지에만 주입되므로, 로그인 전(카카오 로그인 페이지)에는 아무 동작도 하지 않습니다.
  로그인해서 선물함 화면을 연 이후부터 동작합니다.
- 목록 화면(`/giftbox/inbox`)에는 각 기프티콘 카드에 "D-16"처럼 남은 일수만 배지로 표시되고,
  실제 "기간 연장" 버튼은 카드를 눌러 들어간 **상세 화면**(`/giftbox/inbox/detail/<id>`)에 있습니다.
  그래서 이 확장은 목록에서 D-30 이내 항목을 찾아 큐에 담아두고, 상세 화면으로 하나씩 자동 이동하며
  "기간 연장"을 시도한 뒤 목록으로 돌아옵니다.
- 카카오 화면은 리액트로 만들어져 있어 CSS 클래스명이 빌드마다 바뀌고, 버튼도 `<button>`이 아니라
  `<div>`로 만들어진 경우가 많습니다. 그래서 태그 종류나 클래스명이 아니라 **화면에 보이는 텍스트**를
  가진 가장 안쪽 요소를 찾아 클릭하는 방식으로 만들었습니다.
- "기간 연장"을 누르면 뜨는 확인창은 페이지 안의 DOM 팝업이 아니라 브라우저 네이티브 `confirm()`이라,
  스크립트로 클릭이 불가능합니다(브라우저가 의도적으로 막아둔 제약). 그래서 `confirm-override.js`가
  페이지 로드 전에 `window.confirm`을 자동 확인(`true`)으로 미리 덮어씁니다.
- 이 매칭 방식은 실제 화면을 보며 여러 번 수정한 것이라 이전보다 정확하지만, 카카오가 화면을 바꾸면
  다시 깨질 수 있습니다. 안 맞으면 문제되는 버튼/카드를 개발자도구(F12)에서 우클릭 → Copy → Copy outerHTML로
  복사해서 알려주세요. 스크린샷보다 이 방법이 훨씬 정확하게 고칠 수 있습니다.
- 기프티콘마다 "기간 연장"이 아예 없을 수도 있습니다(카카오가 상품별로 다르게 운영). 그런 경우 로그에
  "연장 버튼 없음"으로 기록되고, 같은 항목을 다시 시도하지 않습니다.
- 처리한 기프티콘은 id로 기록해서 같은 항목을 반복 처리하지 않습니다(팝업의 "처리 기록 초기화"로 리셋 가능).

## 설치

1. Chrome에서 `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 폴더(`kakao-gifticon-extender`) 선택

GitHub에서 ZIP으로 받은 경우, 코드가 업데이트될 때마다 ZIP을 다시 받아 기존 폴더 내용을 덮어쓴 뒤
`chrome://extensions`에서 새로고침 아이콘을 눌러야 반영됩니다. 새로고침 버튼은 로컬 폴더를 다시 읽을
뿐, GitHub에서 새로 받아오지는 않습니다.

## 사용법

1. 카카오 계정으로 로그인합니다. 자동 실행이 켜져 있으면 `/home` 같은 화면에서 자동으로
   기프티콘 목록 화면(`gift.kakao.com/giftbox/inbox?couponStatus=OPEN`)으로 이동시켜줍니다.
2. 기본값은 자동 실행 켜짐 + D-30 이내입니다. 목록에서 대상을 찾으면 상세 화면으로 하나씩 이동하며
   "기간 연장"을 시도하고, 다 끝나면 목록으로 돌아옵니다.
3. 툴바 아이콘을 눌러 팝업에서:
   - 자동 실행 켜기/끄기
   - 연장 대상 기준 일수 조정
   - "지금 검사 및 연장"으로 수동 실행(목록 화면이면 전체 스캔, 상세 화면이면 그 기프티콘만 즉시 시도)
   - 처리 로그 확인(연장 완료 / 연장 버튼 없음)
   - "처리 기록 초기화"
4. 팝업 상단에 마지막 검사 후 며칠 지났는지 표시됩니다. 30일 이상 지나면 노란색으로 강조되고,
   백그라운드에서 데스크톱 알림도 한 번 띄워줍니다(다시 검사하면 알림이 리셋됩니다).

## 처음 사용 시 권장 사항

자동 실행을 끄고, 실제로 연장 대상 기프티콘이 있는 화면에서 "지금 검사 및 연장"을 한 번 눌러
로그에 "연장 완료"가 찍히는지, 실제 카카오톡 선물함에서 유효기간이 늘어났는지 확인한 뒤
자동 실행을 켜는 것을 권장합니다. 실제 "연장 신청"이 확정되는 동작이라 되돌릴 수 없습니다.
