# 카카오 기프티콘 유효기간 자동 연장

> 만든 이유와 동작 방식을 정리한 글: [블로그 포스트](https://claude.ai/artifact/5t4mGv2mGEgktEogxDvNAY)

gift.kakao.com 선물함 화면에서 유효기간이 얼마 남지 않은(기본 30일 이내) 기프티콘에 대해
카카오가 이미 제공하는 "유효기간 연장" 버튼을 자동으로 클릭해줍니다.
새로운 권한을 만들어내는 게 아니라, 사용자 본인이 로그인한 화면에서 반복 클릭을 대신 해주는 도구입니다.

## 동작 방식과 한계

- `gift.kakao.com/*` 페이지에만 주입되므로, 로그인 전(카카오 로그인 페이지)에는 아무 동작도 하지 않습니다.
  로그인해서 선물함 화면을 연 이후부터 동작합니다.
- 카카오 화면은 리액트로 만들어져 있어 CSS 클래스명이 빌드마다 바뀌는 경우가 많습니다.
  그래서 클래스명이 아니라 **버튼에 보이는 텍스트**("유효기간 연장", 확인 팝업의 "연장/확인" 등)를 기준으로 동작하도록 만들었습니다.
- 저는 로그인된 실제 화면의 HTML을 확인할 방법이 없어서, 이 텍스트 매칭 방식이 실제 화면과 정확히 맞는지 검증하지 못했습니다.
  설치 후 테스트해보시고, 버튼이 안 눌리거나 엉뚱하게 동작하면 실제 버튼/팝업 문구를 알려주세요. `content.js`의 정규식만 고치면 됩니다.
- 한 번 처리한 기프티콘은 내용 해시로 기록해서 같은 항목을 반복 클릭하지 않습니다(팝업의 "처리 기록 초기화"로 리셋 가능).

## 설치

1. Chrome에서 `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 폴더(`kakao-gifticon-extender`) 선택

## 사용법

1. 카카오 계정으로 로그인합니다. 자동 실행이 켜져 있으면 `/home` 같은 화면에서 자동으로
   기프티콘 목록 화면(`gift.kakao.com/giftbox/inbox?couponStatus=OPEN`)으로 이동시켜줍니다.
2. 기본값은 자동 실행 켜짐 + D-30 이내입니다. 화면이 바뀔 때마다 자동으로 스캔해서 대상이 있으면 연장을 시도합니다.
3. 툴바 아이콘을 눌러 팝업에서:
   - 자동 실행 켜기/끄기
   - 연장 대상 기준 일수 조정
   - "지금 검사 및 연장"으로 수동 실행
   - 처리 로그 확인(연장 완료 / 버튼은 눌렀지만 확인 팝업을 못 찾음)
   - "처리 기록 초기화"
4. 팝업 상단에 마지막 검사 후 며칠 지났는지 표시됩니다. 30일 이상 지나면 노란색으로 강조되고,
   백그라운드에서 데스크톱 알림도 한 번 띄워줍니다(다시 검사하면 알림이 리셋됩니다).

## 처음 사용 시 권장 사항

자동 실행을 끄고, 실제로 연장 대상 기프티콘이 있는 화면에서 "지금 검사 및 연장"을 한 번 눌러
로그에 "연장 완료"가 찍히는지, 실제 카카오톡 선물함에서 유효기간이 늘어났는지 확인한 뒤
자동 실행을 켜는 것을 권장합니다. 실제 "연장 신청"이 확정되는 동작이라 되돌릴 수 없습니다.
